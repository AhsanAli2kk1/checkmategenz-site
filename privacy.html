Privacy Policy

CheckmateGenz Bot
Last updated: October 2026

What this app is

CheckmateGenz Bot is a private tool used only by its owner to manage the YouTube channel @CheckmateGenz. It is not available to the public.

Data the app accesses

With the owner's permission, the app uses the Google YouTube API to upload videos to the owner's own channel and, optionally, to read the channel's own analytics (such as views and watch time).

Data we collect from other people

None. The app has no other users and does not collect, store, or process personal data about any other person.

How data is used and stored

Channel data is used only to upload videos and to produce a private weekly performance summary for the owner. Login credentials (an OAuth token) are stored as encrypted secrets in the owner's private GitHub repository. No data is sold, shared, or transferred to third parties.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
